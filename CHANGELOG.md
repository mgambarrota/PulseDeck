# Changelog

## 0.1.0 — Unreleased

- Dashboard locale con sei viste: sistema, CPU, memoria, dischi, rete e processi.
- Interfaccia responsive con storico breve CPU/RAM e animazioni accessibili.
- Proxy di sviluppo, timeout HTTP e riconnessione automatica.
- Fallback per metriche opzionali e contatori protetti da accessi concorrenti.
- Toolchain Angular 21 e builder leggero, con dipendenze inutilizzate rimosse.
- Runtime backend verificato con Python 3.12; requisito minimo Python 3.11.
- CORS limitato alle origini locali e configurabile tramite ambiente.
- Test di compatibilità backend e workflow CI per le tre piattaforme desktop.
